두 번째 API — 우리 학교 급식

  1. ① 아이디어 발산 — 최소 세 개
    🏫 다른 학교를 넣으려면 — 학교 코드를 찾아 확정한다

    다른 학교를 불러오려면 교육청 코드와 학교 코드 두 가지가 필요합니다. AI가 제시한 학교 코드가 실제 코드와 다를 수 있으므로, 공식 응답에서 직접 확인합니다. 코드를 찾는 방법은 학교기본정보 API에 학교 이름을 넣어 조회하는 것입니다. 주소는 https://open.neis.go.kr/hub/schoolInfo?Type=json&SCHUL_NM=학교이름이며, 줄임말은 검색되지 않아 정식 명칭이 필요하고 같은 이름이 여러 지역에 있으면 교육청 코드로 좁혀야 합니다. 확인한 코드는 프롬프트에 직접 적어 주며, 예를 들어 서울시교육청은 B10, 수도여자고등학교는 7010090, 송탄고등학교는 7530480입니다. 교육청 코드는 아래 표에서 확인할 수 있습니다. 학교 코드는 학교마다 다르고 수가 많아 표로 정리할 수 없습니다.

    교육청을 고르고 학교 이름을 넣은 뒤 코드 찾기를 누릅니다.
    지역코드지역코드지역코드
    서울B10부산C10대구D10
    인천E10광주F10대전G10
    울산H10세종I10경기J10
    강원K10충북M10충남N10
    전북P10전남Q10경북R10
    경남S10제주T10

    코드는 알파벳 한 글자에 10을 붙인 꼴입니다. L과 O는 쓰지 않습니다.
