모델 평가 손계산 활동지

AI가 화면에 보여 주던 점수(R², 정확도, 향상도)를 종이 위에서 직접 만들어 봅니다. 사칙연산과 나눗셈이면 충분합니다. 부마다 기본 개념 → 예제(풀이 포함) → 연습 문제 → 스스로 풀기 → 수업 실측 해석의 순서로 되어 있습니다. 문제를 풀다가 막히면 그 부의 개념 카드로 돌아가 분모가 무엇인지부터 확인합니다.

✍️ 활동지 규칙

계산 과정을 지우지 않습니다. 과정이 곧 점수입니다. 답만 적힌 활동지는 검산할 수 없습니다. 막히면 표의 빈칸부터 채웁니다. 정답은 접힌 상자 안에 있으니, 먼저 끝까지 푼 뒤에 펼칩니다.문제를 푼 뒤 선생님과 답을 확인합니다.학생이 문제를 푼 뒤 인쇄된 정답과 대조합니다. 4부(군집)는 수업 활동지에 없던 보충으로, 개념 이해용입니다.

1부 · 8차시회귀 모델의 평가 — 오차에서 R²까지

개념네 계단

① 오차
실젯값 − 예측값
이 예측은 얼마나, 어느 쪽으로 빗나갔나. 부호가 있다.
② 부호 없애기
|오차| 또는 오차²
양수와 음수가 상쇄되지 않게. 절댓값의 평균이 MAE.
③ MSE
제곱오차의 합 ÷ 개수
평균적으로 얼마나 빗나가나. 큰 실수 하나에 민감하다.
④ R²
1 − (SSE ÷ SST)
SSE = 내 모델의 제곱오차 합, SST = 평균만 찍는 모델의 제곱오차 합. "평균보다 얼마나 나은가".
오차는 세로 거리, 제곱오차는 그 거리를 한 변으로 하는 정사각형의 넓이입니다.

예제 1오차 · MAE · MSE

내가 만든 기온 예측기의 4일 기록입니다. 오차의 합, MAE, MSE를 구합니다.
월화수목
실제(℃)22252724
예측(℃)23242726
오차(실제−예측)−1+10−2
|오차|1102
오차²1104
  1. 오차를 그냥 더하면 (−1) + 1 + 0 + (−2) = −2. 이 값만 보면 4일에 2도 빗나간 것처럼 보이지만, 실제로는 4일 중 3일을 틀렸습니다. 상쇄 때문입니다.
  2. MAE = (1 + 1 + 0 + 2) ÷ 4 = 1.0. 하루 평균 1도 빗나갑니다.
  3. MSE = (1 + 1 + 0 + 4) ÷ 4 = 1.5. 목요일의 오차 2가 제곱되어 4가 되면서 MSE를 끌어올렸습니다.

예제 2R² — 평균값 기준과 비교하기

어느 도시의 5년치 연평균 기온과 모델의 예측값입니다. R²를 구합니다.

모델의 예측(℃)5671012
오차²10100
(실제 − 평균)²1640416
  1. 실제 값의 평균 = (4 + 6 + 8 + 10 + 12) ÷ 5 = 8. 평균값 기준 모델은 5년 내내 8만 예측합니다.
  2. 평균값 기준의 제곱오차 합 SST = 16 + 4 + 0 + 4 + 16 = 40.

  4. R² = 1 − (2 ÷ 40) = 1 − 0.05 = 0.95. "내 모델은 평균만 찍는 모델이 내는 오차의 95%를 없앴다."

스스로 풀기1부

문제 1. 5년치 실제 기온 5, 7, 9, 11, 13과 예측 6, 8, 8, 10, 13. 평균·SST·SSE·R²를 구하세요.
정답 확인

평균 9 · SST = 16 + 4 + 0 + 4 + 16 = 40 · 오차 −1, −1, +1, +1, 0 → SSE = 4 · R² = 1 − 4/40 = 0.90

문제 2. 영화 3편의 실제 관객(만 명) 20, 40, 90과 예측 30, 40, 80. R²를 구하세요. 다른 세 영화에서도 SSE는 200으로 같고, SST는 2600보다 작지만 0보다 크다고 가정할 때 R²는 어떻게 달라집니까?
정답 확인

평균 50 · SST = 900 + 100 + 1600 = 2600 · SSE = 100 + 0 + 100 = 200 · R² = 1 − 200/2600 ≈ 0.923. SSE가 200으로 같을 때 SST(분모)가 작아지면 200/SST가 커지므로 R²는 낮아진다. R²는 데이터의 퍼짐에도 달려 있다.

문제 3. 실제 값 10, 12, 14에 대해 세 번 모두 16으로 예측하는 엉터리 모델이 있습니다. SST·SSE·R²를 구하고, R²가 음수라는 것이 무슨 뜻인지 한 문장으로 쓰세요.
정답 확인

평균 12 · SST = 4 + 0 + 4 = 8 · SSE = 36 + 16 + 4 = 56 · R² = 1 − 56/8 = −6. 평균만 찍는 평균값 기준 모델보다도 못하다는 뜻이다. R²는 음수가 될 수 있다.

문제 4. 계산 없이 답하기. 데이터의 평균값만 매번 찍는 모델의 R²는 얼마이며, 그 까닭은 무엇입니까?
정답 확인

0. 이 모델의 SSE가 곧 SST이므로 1 − 1 = 0이다.

문제 5. 어느 모델의 MSE가 0.4이고 데이터가 5개입니다. 제곱오차의 합(SSE)은 얼마입니까? 평균 모델의 제곱오차 합이 40이라면 R²는?
정답 확인

SSE = 0.4 × 5 = 2 · R² = 1 − 2/40 = 0.95. MSE는 SSE를 개수로 나눈 값이므로 거꾸로 곱하면 SSE가 나온다.

수업 실측숫자를 해석하기

활동지 기본 문제에서 평균값 기준의 제곱오차 합은 40, 고른 모델의 제곱오차 합은 10이었습니다. 7차시 영화 예측기에서는 변수 조합을 바꿀 때마다 테스트 점수가 달라졌습니다.

(1) R² = 1 − (10 ÷ 40) = 0.75입니다. 이 값을 "예측의 75%가 맞았다"로 읽으면 왜 틀립니까?

(2) 변수를 늘렸는데 테스트 점수가 오히려 내려갔다면 무엇을 뜻합니까?

(3) 개봉 전에는 알 수 없는 값을 입력에 넣었더니 점수가 크게 올랐습니다. 이것을 성능 개선이라 부를 수 있습니까?

(4) "R²가 높은 모델 = 미래를 잘 맞히는 모델"이라는 주장의 허점을 학습 범위 밖 예측을 예로 쓰세요.

예시 답

(1) R²는 평균값 기준과 비교해 제곱오차 합이 얼마나 줄었는지를 나타내는 비율이다. 맞힌 비율이 아니다.

(2) 관련이 적은 변수를 넣으면 학습에 쓰지 않은 데이터에서는 점수가 떨어질 수 있다. 변수를 늘린다고 점수가 반드시 오르지는 않는다.

(3) 아니다. 예측 시점에 확보할 수 없는 값을 넣은 것이므로 실제로는 쓸 수 없는 조건에서 나온 점수다.

(4) R²는 가진 데이터 안에서의 성적이다. 학습 범위 밖을 예측하면 직선은 숫자를 내놓지만 그 값이 실제와 맞는지는 이 점수가 보장하지 않는다.
